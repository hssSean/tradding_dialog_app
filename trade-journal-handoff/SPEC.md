## 1. 設計原則

1. **背景就是資料**：月相代表今天的精神力，最前面的山脊是本季權益曲線。這不是裝飾，要接真實資料。
2. **經驗值只來自過程，不來自盈虧**。盈虧照常顯示，但不換算成任何獎勵；獎勵只能換外觀。
3. 不做「今天交易 N 筆」之類會逼人進場的任務；連續天數在休息日也要能維持。
4. 避免制式 AI 介面：不要每個區塊都套同樣的圓角卡片。段落用細墨線分隔，標題用楷書，評級用印章。全頁只有「立作戰卡」一個亮色區塊。
5. 盈虧顏色**不用紅綠**（台灣紅漲綠跌、幣圈綠漲紅跌，兩邊習慣相反）：賺用玉色 `--jade`，賠用赭色 `--ochre`，數字一律帶正負號。

### 山水主視覺的實作細節（參考 `Scene` 元件）

- 用 `<canvas>` 畫，DPR 上限 2，`ResizeObserver` 只在寬度改變時重畫。
- 遠山：`ridgeLine(W, baseY, amp, seed)`，脊狀噪聲（`1-|sin|`）疊加，固定 seed（7、23、91）讓每次長一樣。三層 baseY 分別是高度的 55%、63%、72%。每層用由上往下淡出的漸層填色，層與層之間加一道霧帶。
- 稜線亮邊：橫向漸層，越靠右（月亮那側）越亮，再偏移 1.4px 描第二筆做出乾筆感。
- **前山＝權益曲線**：
  - 取本季已平倉交易的累積 R（起點 0）。
  - 先做指數平滑 `sm[i] = 0.45 * sm[i-1] + 0.55 * cum[i]`，**最後一點強制等於真實累積值**。
  - 縱向映射到主視覺高度的 66%～86%，橫向從 −6px 到 `W − 34px`，用 Catmull-Rom 取樣成平滑曲線，終點後緩降出畫面。
  - 終點畫一個發光的月色圓點，旁邊標「今 +x.xR」（顯示真實累積值，不是平滑值）。
  - 本季少於 2 筆時，前山畫成平緩的固定稜線，說明列改成「本季還沒有交易」。
- 進場動畫：前山從左往右展開 1.7 秒（easeOutCubic）。`prefers-reduced-motion` 時直接畫完、霧不飄。
- 月相：亮面比例 = `hp / 100`。SVG 路徑在參考碼 `Moon` 元件裡（右半圓＋橢圓弧，`rx = |2k−1|·r`）。

## 4. 遊戲化規則

### 4.1 作戰卡（進場前計畫）

欄位：代號、方向、Setup（從圖鑑清單選或新增）、進場價、止損價、目標價（選填）、預計風險 %（由帳戶權益自動算）、進場理由、當下情緒（1–5）。

- 作戰卡的 `createdAt` **早於**交易的 `openedAt` 才算「進場前」。
- 進場後才補填：只拿一半經驗值（+10），評分仍視為沒有作戰卡。
- 情緒 ≥ 4 時，存檔前顯示二次確認（頁面內的確認區塊，不要用 `confirm()`）。
- 預計風險超過目前階級上限時，風險數字顯示為赭色並提示。

### 4.2 每筆交易評分（0–100）

| 項目 | 滿分 | 條件 |
|---|---|---|
| 進場前有作戰卡 | 20 | 作戰卡在進場前存檔 |
| 有初始止損 | 20 | `initialStop` 不為空 |
| 風險在上限內 | 20 | `riskPct ≤ 上限` 得 20；`≤ 1.25 × 上限` 得 10；超過得 0 |
| 沒有逆向移動止損 | 20 | 做多時止損沒往下移、做空時沒往上移（往有利方向移、移到保本都不扣分） |
| 及時復盤 | 20 | 平倉後 24 小時內得 20；72 小時內得 10；尚未復盤時評分標為「暫定」 |

**評級**：S ≥ 90、A ≥ 75、B ≥ 65、C ≥ 50、D < 50。

**修正**：
- 在冷卻期開單（上頭違規）：分數上限 74（最高 B）。
- 當天精神力已歸零後開的單：評級再降一級。

> 參考畫面中的 94、85 只是示意數字。

### 4.3 四象限標籤

「守紀律」的定義是評分 ≥ 75（A 以上）。

| | R > 0 | R ≤ 0 |
|---|---|---|
| 守紀律 | **好的獲利**（玉色） | **好的虧損**（霧藍） |
| 違規 | **運氣好的壞交易**（月色＋警示圖示） | **壞的虧損**（赭色） |

「運氣好的壞交易」要在下方多一行，寫出扣分最多的那一項，例如「沒有作戰卡就進場，這筆賺的不是你的優勢」。

### 4.4 精神力（每日 HP，月相）

- 每天 00:00（台北時間）回滿 100。
- 每開一筆：−10。
- 每筆虧損平倉：再扣 `round(10 × |R|)`；如果是連續第 2 筆以上的虧損，這部分加倍。
- 最低為 0。

| HP | 狀態文字 | 效果 |
|---|---|---|
| ≥ 60 | 穩定 | 無 |
| 30–59 | 注意疲勞 | 下一筆的作戰卡需要二次確認 |
| 1–29 | 瀕臨休兵 | 建議今天到此為止 |
| 0 | 今日休兵 | 之後的交易評級降一級 |

驗算：當天兩筆，一筆獲利、一筆 −1R → 100 − 10 − 10 − 10 = 70（與參考畫面一致）。

### 4.5 狀態異常（Debuff）

| 名稱 | 觸發條件 | 顯示時間 | 後果 |
|---|---|---|---|
| **上頭（冷卻）** | 任一筆虧損平倉後自動進入 15 分鐘冷卻 | 顯示倒數 | 冷卻中開單 = 上頭違規：評分上限 B、倉位降一階、晉升進度歸零 |
| **報復** | 虧損後的下一筆，風險 % 大於上一筆的 1.2 倍 | 60 分鐘 | 記入情緒控管 |
| **過度自信** | 連贏 3 筆後的下一筆，風險 % 大於前 3 筆平均的 1.2 倍 | 60 分鐘 | 記入情緒控管 |
| **FOMO** | 進場時沒有作戰卡 | 60 分鐘 | 記入耐心 |
| **疲勞** | 台北時間 02:00–06:00 開單，或當天第 6 筆以上 | 到當天結束 | 記入耐心 |

冷卻倒數要即時計算，例如虧損平倉後 2 分 30 秒應顯示「冷卻 12:30」。參考碼裡的文字是寫死的示意。

### 4.6 倉位階級

| 階 | 名稱 | 單筆風險上限 | 晉升條件 |
|---|---|---|---|
| 1 | 見習 | 0.5% | 預設 |
| 2 | 正式 | 1.0% | 在見習累積 30 筆 A 以上 |
| 3 | 老手 | 1.5% | 升上正式後再累積 50 筆 A 以上，**且**本季最大回撤 < 8% |

- 上頭違規：降一階（最低見習），該階的晉升計數歸零。
- 最大回撤：本季帳戶權益（每筆平倉後的權益）從高點到低點的最大跌幅 %。

### 4.7 角色屬性（本季，0–100，至少 5 筆才顯示）

| 屬性 | 計算 |
|---|---|
| 風控 | 有初始止損且風險在上限內的交易比例 |
| 復盤 | 平倉後 24 小時內完成復盤的比例 |
| 執行力 | 進場前有作戰卡、且沒有逆向移動止損的比例 |
| 耐心 | 100 − 被標記 FOMO 或疲勞的比例 |
| 情緒控管 | 100 − 被標記上頭、報復或過度自信的比例 |

最弱項用赭色標出，並給一句對應建議：

| 最弱項 | 建議 |
|---|---|
| 風控 | 下一筆進場前先把止損填進作戰卡 |
| 復盤 | 今天平倉的單，睡前寫完復盤 |
| 執行力 | 這週不要動止損，只允許往有利方向移 |
| 耐心 | 沒有作戰卡就不進場 |
| 情緒控管 | 連虧 2 筆後離開螢幕 30 分鐘 |

### 4.8 職業（本季至少 10 筆才判定）

- 持倉時間中位數 < 1 小時：**刺客型**（剝頭皮）
- 否則：**遊俠型**（波段）
- 若勝率 < 40% 且平均獲利 R ÷ 平均虧損 R ≥ 2.5，改判為**狙擊手型**

### 4.9 經驗值與等級

| 來源 | 經驗值 |
|---|---|
| 作戰卡（進場前） | +20 |
| 作戰卡（進場後補填） | +10 |
| 24 小時內復盤 | +20；附截圖標註再 +10 |
| 每筆交易的評級 | S +40、A +30、B +15、C +5、D 0 |
| 任務 | 依任務 |
| 成就 | 依成就 |

**盈虧本身不給任何經驗值。**

- 升到下一級需要 `250 × 目前等級`（Lv.12 → 13 要 3,000）。
- 等級稱號：Lv.1–5 見習交易員、6–14 紀律學徒、15–29 冷靜之手、30 以上冷血獵人。
- 擊敗心魔或解成就得到的稱號另外收藏，可以替換顯示。

### 4.10 本月心魔（Boss）

- 每月 1 日，從上個月的違規中挑**次數最多**的一種當心魔：逆向移動止損、無作戰卡、超風險、上頭、報復、過度自信、疲勞。
- 名稱對照：逆向移動止損 →「移動止損者」、無作戰卡 →「衝動者」、超風險 →「重倉者」、上頭 →「上頭者」、報復 →「報復者」、過度自信 →「自滿者」、疲勞 →「夜行者」。
- 血量 30。每平倉一筆**沒有**該違規的交易，血量 −1；只要有一筆犯了，血量回滿 30。
- 擊敗後得到稱號「鐵律武士」＋300 經驗值（之後每個心魔可以有自己的稱號）。
- 上個月沒有任何違規時，本月不出現心魔，該區塊改顯示「本月無心魔」。

### 4.11 任務（功課）

| 週期 | 任務 | 經驗值 |
|---|---|---|
| 每日 | 開盤前寫市場觀察 | +30 |
| 每日 | 復盤今日所有交易（顯示 n/m，沒交易時自動隱藏） | +40 |
| 每週 | 標註 3 張進場截圖 | +80 |
| 每週 | 寫下本週最大的錯誤 | +60 |
| 每月 | 檢查一張圖鑑卡，決定保留或淘汰 | +100 |

- **禁止**任何以交易次數為目標的任務。
- 連續天數：當天有完成「當日復盤」就算一天；沒交易的日子寫了市場觀察也算（所以休息日也能維持連續紀錄）。

### 4.12 Setup 圖鑑

- 每種 Setup 是一張卡。已平倉樣本 ≥ 20 筆才「鑑定」，顯示勝率、期望值（平均 R）、樣本數。
- 未滿 20 筆：模糊剪影、期望值顯示「？？？」、進度 n/20。
- 鑑定後期望值 < 0：標成「詛咒卡」（赭色軸桿＋詛咒章）。
- 標題顯示「已鑑定 x / 總數」。

### 4.13 成就（第一版）

| 成就 | 條件 |
|---|---|
| 鐵律 | 連續 50 筆沒有逆向移動止損 |
| 空手也是倉位 | 整週零交易，但每天都寫了市場觀察 |
| 懂得收手 | 連虧 3 筆後當天沒有再開單 |
| 史官 | 累積 100 篇復盤 |
| 日誌控 | 連續 20 筆都有作戰卡 |
| 浴火重生（隱藏） | 回撤超過 5% 後回到前高，期間沒有任何上頭違規 |
| 佛系（隱藏） | 連續 10 筆情緒評分都是 3 |

### 4.14 賽季

- 一個月一季。紀律分數 = 本季所有交易評分的平均。
- 月底結算時生成回顧卡：本季總 R、最佳與最差一筆、紀律分數、心魔結果、屬性變化。
- 獎勵**只能換外觀**（主題配色、頭像框）。iOS 的主畫面圖示無法由網頁動態更換，不要做成獎勵。

## 7. 主畫面圖示與 PWA

### 新圖示

夜空、盈凸月、往右上走的權益曲線山脊，終點一點月光；和首頁同一套語言。原始檔是 `icons/icon-source.svg`。主體都在中心 80% 圓內，所以同一張圖也能當 Android 的 maskable 圖示。所有 PNG 都是不透明的 RGB（iOS 會把透明處填黑，所以不能有透明背景）。

### 安裝步驟

1. 把 `icons/` 整個資料夾放到 `public/icons/`（Vercel 會原樣提供）。
2. 把 `pwa/manifest.webmanifest` 放到 `public/manifest.webmanifest`。
3. 把 `pwa/head-snippet.html` 的內容合併進 `index.html` 的 `<head>`，刪掉舊的 favicon、apple-touch-icon 與重複的 viewport。
4. 狀態列設成 `black-translucent`，夜空會延伸到瀏海下面。所以主視覺頂端一定要加 `env(safe-area-inset-top)` 的內距（參考 CSS 已處理），分頁列底部要加 `env(safe-area-inset-bottom)`。
5. 圖示網址帶 `?v=2` 避免快取。

### iPhone 上更新圖示（請轉告使用者）

iOS 在「加入主畫面」那一刻就把圖示存起來了，之後網站換圖示也**不會自動更新**。部署完成後：

1. 長按主畫面上舊的圖示 → 移除 App（只是移除捷徑，資料在伺服器上不受影響）。
2. 用 Safari 打開網站 → 分享 → 加入主畫面。名稱會自動帶入「交易日誌」。
3. 如果還是舊圖示：設定 → Safari → 清除歷史記錄與網站資料，再重新加入。

## 8. 實作注意

- 遊戲化計算全部放在純函式模組，**至少**為以下情境寫單元測試：
  - 精神力：兩筆交易、其中一筆 −1R → 70；連續第二筆虧損時的加倍扣分；最低為 0。
  - 評分：五個項目的部分給分；上頭違規時上限 74；精神力歸零後降一級；尚未復盤時標為暫定。
  - 四象限分類的邊界（R = 0 算虧損那邊；評分剛好 75 算守紀律）。
  - 逆向移動止損：做多往下移、做空往上移才算；移到保本不算。
  - 晉升與降階：計數、回撤條件、降階時歸零。
  - 等級：Lv.12 升級需要 3,000。
  - 心魔：犯一次血量回滿。
  - 權益曲線平滑：最後一點等於真實累積 R。
- 沒有初始止損的交易無法算 R：不畫進前山、不算進圖鑑期望值，但仍要評分（「有初始止損」那項 0 分）。
- 參考碼裡的 canvas 顏色是寫死的十六進位值，和 token 一致；如果之後改 token，要一起改。
- 不要用 `alert()`／`confirm()`，二次確認一律做成頁面內的區塊。
- 尊重 `prefers-reduced-motion`。
- 觸控目標至少 44px。

## 9. 建議實作順序

1. **視覺與圖示**：套上新的設計 token、字型、首頁版面與山水主視覺，前山先接現有交易資料的累積 R；更換圖示、manifest、head 標籤。完成後使用者就能先在 iPhone 上看到新樣子。
2. **資料補欄位＋作戰卡表單**：`BattleCard`、`initialStop`、`stopEdits`、`equityAtEntry`、`setupId`、`emotion`、`review`。舊資料缺欄位時，評分以「暫定／資料不足」顯示，不要當成違規。
3. **遊戲化引擎＋測試**：評分、評級、四象限、精神力、Debuff、倉位階級、屬性、經驗值與等級。
4. **心魔、任務、圖鑑、成就、賽季回顧卡**。
